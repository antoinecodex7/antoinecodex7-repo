Thème immersif sur mesure pour ANTOINE CODEX (Nice · Côte d'Azur).

== Description ==

Thème classique WordPress : champ de particules WebGL maison (sans bibliothèque), révélations au défilement,
gabarits immersifs pour les pages clés (Diagnostic d'entreprise & Stratégie de croissance, Services,
Méthodologie, Fondateur, Contact), passerelle serveur pour ANTOINE CODEX CORE, compatibilité Polylang / WPML,
extensions SEO et extensions de formulaires. Version statique automatique pour « prefers-reduced-motion »,
sans WebGL et sans JavaScript.

Guide complet : README.md (installation, connexion de CORE, vérifications, limites connues).

== Installation ==

1. Apparence → Thèmes → Ajouter → Téléverser un thème → choisir le fichier ZIP → Installer.
2. Activer d'abord sur une copie de préproduction.
3. Apparence → Diagnostic de migration : vérifier les fonctions de l'ancien thème à conserver.
4. Apparence → Personnaliser → ANTOINE CODEX : pages clés, coordonnées, textes.
5. Apparence → ANTOINE CODEX CORE : relier le chatbot.
